# Resonance Atlas provenance and license

Original procedural vector compositions made for DCC-MCP in October 2026.
No reference artwork, logos, maps, stock photographs, generated bitmap art, or
third-party datasets are incorporated. Mathematical curves are illustrative,
normalized diagrams, not measured acoustic data or a pressure simulation.

Original artwork plans retain the contributor's rights; no blanket MIT artwork
grant is made. The generator and composition scripts are MIT, following the host
repository. DejaVu Sans is installed separately under its own permissive font
license; no font binary is bundled. Inkscape is separately installed GPL software.

References consulted for technique/context, not copied:
- https://wiki.inkscape.org/wiki/Extension_reference (native parametric curves)
- https://inkscape.gitlab.io/extensions/documentation/source/inkex.bezier.html
- https://www.itsnicethat.com/tags/technology (2026 motion/design context)

Production boundary: typed JSON plans -> DCC-MCP gateway -> native Inkscape
extension -> SVG/PNG/PDF. Pillow and FFmpeg assemble the exported PNGs into a
12-second film. The film is explicitly labeled as an assembly film and is not a
screen recording. Source vector geometry is created by Inkscape, not an XML writer.
